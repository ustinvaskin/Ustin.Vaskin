PRODUCT & RESEARCH

TUNDRA / REPAIR 008

Can you spot the bug?

This program should print the target value, 20. It prints 30.

  1. val rows = [
  2. { label: "low", value: 10 },
  3. { label: "target", value: 20 },
  4. { label: "high", value: 30 }
  5. ];
  6.  
  7. val selected = rows[2];
  8. print(selected.value);
Which line would you change?
Reveal traceHide trace

rows[2] selected the third record, labeled “high”. Its value was 30. The target is the second record. Changing line 7 to rows[1] gives 20.
