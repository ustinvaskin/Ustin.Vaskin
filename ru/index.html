TUNDRA / ЗАДАЧА 008

Где ошибка?

Программа должна показывать 20, а показывает 30.

  1. val rows = [
  2. { label: "low", value: 10 },
  3. { label: "target", value: 20 },
  4. { label: "high", value: 30 }
  5. ];
  6.  
  7. val selected = rows[2];
  8. print(selected.value);
В какой строке ошибка?

✓ ОШИБКА НАЙДЕНА

Посмотреть разборСкрыть разбор

В этом списке счёт начинается с нуля. Поэтому rows[2] берёт третью запись со значением 30. Чтобы выбрать вторую запись и получить 20, в строке 7 нужно заменить rows[2] на rows[1].
